# MESH-X Mobile Application

This directory will contain the Flutter-based mobile client application for Android and iOS.

## Technology Stack
- **Framework**: Flutter 3.41+ / Dart 3.11+
- **State Management**: Riverpod
- **Local Persistence**: SQLite (`sqflite`)
- **Bluetooth Low Energy**: `flutter_blue_plus`
- **Design System**: Hallmark Dark Theme with strict token architecture

## Setup & Initialization
This codebase will be initialized in **Phase 3: Flutter App Foundation** following approval of Phases 0, 1, and 2.
Do not place ESP32 C/C++ firmware files inside this directory.
